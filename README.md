# Notiee - 📅 日程感知 AI 极速随手记

Notiee 是一款专为学生和职场人打造的 **iOS 原生 (SwiftUI) 极速相机随手记与 AI 知识提炼工具**。

它彻底解决了“拍照容易整理难”的痛点：通过导入日历或课表，在你按下快门的瞬间，自动关联当前时间段的课程或会议上下文；同时通过异步队列调用 AI 大模型，自动对图片进行 OCR、生成 100 字摘要、提炼精准小标题和提取待办事项 (To-do List)，将零散的课堂/会议板书照片无缝转化为结构化的知识流。

---

## ✨ 核心特性

- **📅 Today (今日控制中心)**：高亮展示当前正在进行的日程，纵向呈现今日时间轴、待办事项和今日记录，全面掌控今日学习/工作进度。
- **📷 拍记 (极速相机交互)**：提供暗色调的沉浸式极速连拍体验。拍照后无任何阻断式弹窗，照片通过平滑动画飞入暂存区，并根据当前时间自动感知并绑定日程。若无活跃日程，自动归入“未分类”暂存区。
- **📓 记录 (知识库归档)**：支持通过标题、摘要、OCR 原文等多维度关键字进行全文精准检索。按日程及时间线清晰归档。
- **👤 我 (安全自助 AI)**：支持自主配置文本处理模型 (Text LLM) 与图像识别模型 (Vision LLM)。敏感的 API Key **加密存储于本机设备 Keychain**，不写入普通 UserDefaults，充分保护隐私。
- **🚀 离线优先与高可靠**：支持完全无网环境下的本地保存与快速检索，后续网络恢复后将自动异步处理。

## 🛠️ 技术架构

项目基于 **离线优先 (Offline-First)** 和 **MVVM** 架构设计：

- **UI 框架**：100% 原生 SwiftUI，严格遵循 Apple *Human Interface Guidelines* (HIG) 设计规范，包含原生的毛玻璃效果 (Blur)、交互式半屏抽屉 (BottomSheet) 等。
- **核心数据流**：由 `@MainActor` 修饰的单例 `NotieeStore` 统一管控，保障数据流动的一致性与 UI 响应速度。
- **数据持久化**：本地 JSON 序列化存储记录，设置项利用安全沙盒方案（UserDefaults + Keychain 密钥托管）。
- **测试覆盖**：项目配套完善的单元测试（涵盖日程匹配逻辑、Today 视图筛选、持久化 Store、设置页状态等），保障代码的健壮性。

## 🚦 快速开始

### 运行环境
- **iOS 17.0+**
- **Xcode 15.0+**
- **Swift 5.9+**

### 运行与测试
1. 在 Mac 上使用 Xcode 打开目录下的 `Notiee.xcodeproj` 项目文件：
   ```bash
   open Notiee.xcodeproj
   ```
2. 选择合适的 iOS 模拟器设备（推荐 iPhone 15 或更新机型）。
3. 按下 `Cmd + R` 编译并运行项目。
4. 按下 `Cmd + U` 运行单元测试（目前包含 17 项完整覆盖的测试用例，确保逻辑正确）。
