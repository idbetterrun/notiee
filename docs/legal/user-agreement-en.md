## 6. AI Features Special Terms

6.1 **AI Service Provision**: Notiee+ connects directly to the AI provider configured by the user with the user's API key. The free Notiee app accesses supported AI models through Notiee's self-hosted backend using server-managed credentials.

6.2 **Data Processing Description**:
   - Text and images required for AI processing are relayed to supported AI models through Notiee's self-hosted backend in the free app. In Notiee+, they are sent directly to the AI provider configured by the user.
   - Notti user messages, answer requests, and local context required by Agent mode follow the transport path for the applicable edition described above.
   - The Notti memory database and vectors are encrypted locally and are not synchronized through iCloud. To generate answers or extract memory, the current user message, confirmed tool results, and a bounded set of locally matched memory candidates may be sent temporarily to the selected AI model. The full memory database is not uploaded, and unconfirmed sensitive memories are not recalled.
   - Semantic search computes vectors locally on the device by default. Snapnote text is sent to an Embedding API through the applicable edition's transport path only when the user manually enables "High-Quality Cloud Search" in Labs. The "Deep Recall" related recommendations on detail pages always use local vectors and are not transmitted externally.

6.3 **WebFetch Feature**: In Agent mode, Notti can fetch web content from a specified URL based on user instructions. This feature uses temporary network sessions (cookies/cache are not persisted) and includes built-in security mechanisms that prohibit access to local and intranet addresses.

6.4 **User Responsibility**: Users are responsible for obtaining their own API keys and complying with the terms of service and service agreements of the corresponding AI service providers.

6.5 **AI Output Disclaimer**: AI-generated summaries, to-dos, conversation responses, and other content are for reference only and do not constitute professional advice (including but not limited to professional advice in legal, medical, financial, and other fields). Users should independently assess the accuracy and applicability of AI outputs.
