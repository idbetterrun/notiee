## 六、AI 功能特别条款

6.1 **AI 服务提供方式**：用户自行配置 API Key，连接用户指定的 AI 服务商（如 OpenAI、DeepSeek、Anthropic、阿里云百炼、火山引擎、MiniMax 等）。Notiee 不提供自有的 AI 云服务。

6.2 **数据处理说明**：
   - 文本和图片将发送至用户配置的 AI 服务商进行处理，Notiee 不在中间截留或存储。
   - Spark AI 助手的对话内容（包括用户消息和 AI 回复）将发送至用户配置的 AI 服务商。
   - Agent 模式下，Spark 可能调用工具访问用户的拍记、日程、待办等本地数据，相关数据可能作为上下文发送至 AI 服务商。
   - 语义检索功能默认在设备本地计算向量；仅当用户在实验室手动开启"高质量云端检索"时，才会将拍记文本发送至用户配置的 AI 服务商的 Embedding 接口。详情页的「深度联想」相关推荐固定使用本地向量，不外传。

6.3 **WebFetch 功能**：Agent 模式下，Spark 可根据用户指令抓取指定 URL 的网页内容。此功能使用临时网络会话（不持久化 Cookie/缓存），并内置安全防护机制，禁止访问本地及内网地址。

6.4 **用户责任**：用户需自行获取 API Key 并遵守对应 AI 服务商的使用条款和服务协议。

6.5 **AI 输出免责**：AI 生成的摘要、待办、对话回复等内容仅供参考，不构成专业建议（包括但不限于法律、医疗、财务等领域的专业建议）。用户应自行判断 AI 输出的准确性和适用性。
