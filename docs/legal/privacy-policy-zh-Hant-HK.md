# Notiee 私隱政策

**版本：v1.0.7**
**生效日期：2026 年 8 月 6 日**

---

## 一、引言

我們非常重視您的私隱。本私隱政策旨在向您透明地說明 Notiee（以下簡稱「本應用」）收集哪些資訊、如何使用這些資訊、以及如何保護您的數據安全。

**核心理念：數據都在你手裏。** 本應用是一款本地優先的工具應用，您的所有記錄、筆記和對話都保存在您自己的設備上。

---

## 二、資訊收集與使用

### 2.1 我們不收集的資訊

| 資訊類型 | 說明 |
|----------|------|
| 個人身份資訊 | 無網絡帳戶系統，不收集姓名、電郵、手機號等身份資訊 |
| 位置資訊 | 不請求定位權限，不收集 GPS 坐標 |
| 設備標識符 | 不收集 IDFA、IDFV 或其他設備標識符 |
| 使用行為分析 | 不集成任何分析/統計 SDK，無埋點追蹤 |
| 廣告標識 | 不集成廣告 SDK，無廣告追蹤 |
| 網絡日誌 | 不記錄用戶的網絡請求日誌 |

### 2.2 存儲在設備本地的資訊

| 資訊類型 | 存儲位置 | 用途 |
|----------|----------|------|
| 拍攝的照片 | 設備本地檔案系統 | 記錄內容展示與回顧 |
| OCR 文本、AI 摘要、要點 | 本地 JSON 檔案 | 搜尋與知識回顧 |
| 純文本記錄 | 本地 JSON 檔案 | 手動文字筆記 |
| 待辦事項 | 本地 JSON 檔案 | 任務管理（含截止日期、提醒標記） |
| 自訂資料夾、標籤、日程標籤 | 本地 JSON 檔案 | 分類與日程著色 |
| Notti 對話歷史 | 本地 JSON 檔案 | AI 對話記錄保存與搜尋 |
| Notti 長期記憶與向量 | AES-GCM 加密本地檔案；密鑰獨立存放於 iOS 鑰匙串 | AI 助手個人化記憶與本地召回 |
| 本地帳戶資料（暱稱、頭像） | 本地檔案系統 | 個人資料展示 |
| 語義向量索引（搜尋 / 深度聯想） | 本地檔案系統 | 拍記語義搜尋與相關筆記推薦（端側向量） |
| API Key（AI 密鑰） | iOS Keychain（硬件級加密） | 調用 AI 服務 |
| App 設定偏好（主題、語言、模型配置等） | UserDefaults | 個人化體驗 |
| 日曆日程資訊 | 記憶體中處理，不長期存儲 | 拍照時匹配日程上下文 |

### 2.3 發送至第三方的資訊

以下場景中，數據會發送至所選 AI 模型。Notiee+ 直接連接用戶配置的服務商；免費版 Notiee 經 Notiee AI 中轉後端調用：

| 場景 | 發送內容 | 接收方 | 用戶控制 |
|------|----------|--------|----------|
| AI 拍記處理 | 照片圖片數據 + 文本提示詞 | 用戶配置的 AI 服務商 | 用戶主動觸發拍照後自動處理，可關閉 AI 功能 |
| Notti 對話 | 用戶訊息 + 對話歷史上下文 | 用戶配置的 AI 服務商 | 用戶主動發起對話 |
| Notti 記憶召回與提取 | 目前用戶訊息、已確認的工具結果及少量本地命中記憶候選（免費版最多 5 條，Pro/Plus 最多 10 條） | 所選 AI 模型；免費版經 Notiee 無狀態中轉 | 需同意獨立版本的 Notti 私隱說明；可分別關閉自動記憶和記憶使用 |
| Notti Agent 操作 | 用戶指令 + 相關拍記/日程/待辦數據 | 用戶配置的 AI 服務商 | 用戶主動使用 Agent 模式 |
| WebFetch 網頁抓取 | 目標 URL（由用戶提供） | 目標網頁所在伺服器 | 僅在 Agent 模式下由用戶指令觸發 |
| 雲端語義檢索（可選） | 拍記文本摘要 | 用戶配置的 AI 服務商 Embedding 接口 | **預設關閉**，需在實驗室中手動開啟 |
| iCloud 同步（如開啟） | .tmn 加密歸檔檔案 | Apple iCloud Drive | 用戶手動觸發 |

> **重要說明**：Notiee+ 使用用戶配置的 API Key 和服務商。免費版 Notiee 使用伺服器端密鑰並經 Notiee 後端中轉 AI 請求。Notti 記憶提取接口以無狀態方式處理，不持久化或記錄請求與回應正文。**詳情頁的「深度聯想」相關筆記推薦預設完全在設備本地計算，不向任何伺服器發送數據。**

## 四、數據存儲與安全

| 措施 | 說明 |
|------|------|
| 本地優先 | 所有記錄預設存儲在設備本地，不依賴雲端 |
| Keychain 加密 | API Key 儲存在 iOS Keychain 中，不寫入普通檔案。視乎系統行為，Keychain 項目在 App 卸載後仍可能保留；如需移除，請在卸載前使用 App 內的重設或密鑰移除功能 |
| HTTPS 傳輸 | 所有 AI 服務調用使用 HTTPS 加密傳輸 |
| 無雲端留存 | Notiee 不營運自有伺服器，不收集、不存儲用戶內容數據 |
| iCloud 安全 | 如用戶手動啟用 iCloud 同步，數據存儲在用戶個人的 iCloud Drive，受 Apple 安全體系保護 |
| WebFetch 安全 | 使用臨時網絡會話（不持久化 Cookie/緩存），內置 SSRF 防護，禁止訪問本地及內網地址（localhost、10.x、172.16-31.x、192.168.x 等） |
| 語義檢索本地化 | 預設使用 Apple NLEmbedding 端側向量引擎，所有向量計算在設備本地完成，不上傳至任何伺服器 |
| 無網絡自發請求 | 除用戶主動觸發 AI 處理、Notti 對話、WebFetch 或 iCloud 同步外，本應用不會自發向任何伺服器發送數據 |

## 五、數據分享與披露

5.1 **不向第三方出售、出租或交易用戶數據。**
5.2 僅在以下情況可能披露用戶數據：
   - 法律法規要求
   - 保護開發者或他人的合法權益
   - 用戶明確同意
5.3 AI 服務調用數據發送至用戶自行選擇的 AI 服務商，受該服務商自身的私隱政策約束，與本應用無關。
5.4 WebFetch 抓取的網頁內容由目標網站提供，受該網站的使用條款約束。

## 八、Notti AI 助手私隱說明

Notti 是本應用內置的 AI 助手，具有以下私隱特性：

8.1 **對話內容**：Notti 的對話訊息（用戶輸入和 AI 回覆）按版本對應的路徑發送至所選 AI 模型：免費版經 Notiee 後端中轉，Notiee+ 直接連接用戶配置的 AI 服務商。對話歷史保存在設備本地。
8.2 **Agent 模式**：當用戶使用 Agent 模式時，Notti 可能讀取用戶的拍記、日程、待辦等本地數據作為操作上下文，相關數據可能隨請求發送至 AI 服務商。
8.3 **WebFetch**：Agent 模式下可根據用戶指令抓取網頁內容，使用臨時安全會話，不持久化任何網絡數據。
8.4 **長期記憶**：Notti 的記憶庫和向量使用 AES-GCM 加密儲存在設備本地，不同步到 iCloud。生成回應或提取新記憶時，只會將目前訊息、已確認的工具結果和本地檢索命中的少量候選暫時發送至所選 AI 模型，不會上載完整記憶庫。
8.5 **敏感資訊**：健康、精確地址、聯絡方式、財務和身份資訊需由用戶明確要求記住或確認後才會生效；密碼、驗證碼、API Key、令牌、銀行卡號和私鑰不會儲存為記憶。
8.6 **私隱同意與控制**：新版記憶系統使用獨立版本的私隱同意。用戶可分別關閉自動寫入或記憶使用，關閉不會刪除已有記憶，也可在設定中永久刪除記憶。

## 附錄 A：數據生命週期

```
拍攝 → 本地存儲 → [用戶觸發 AI 處理] → 發送至 AI 服務商 → 返回結果 → 本地存儲
                                ↓
                        [Notti 對話] → 發送至 AI 服務商 → 返回結果 → 本地存儲
                                ↓
                        [Notti 記憶] → 本地召回 → 暫時發送少量命中項 → 加密本地更新
                                ↓
                        [Agent 操作] → 讀取本地數據 → 發送至 AI 服務商 → 執行操作
                                ↓
                        [WebFetch] → 臨時抓取網頁 → 返回正文 → 不持久化
                                ↓
                        [雲端語義檢索（可選）] → 發送文本至 Embedding 接口 → 返回向量 → 本地存儲
                                ↓
                        [iCloud 同步] → 發送至 iCloud Drive
                                ↓
                        [用戶刪除] → 本地檔案移除 + AI 服務商端依其政策處理
```

## 附錄 B：技術實現私隱要點

| 實現 | 說明 |
|------|------|
| 無埋點 | 不集成任何分析/統計 SDK |
| 無廣告 | 不集成廣告 SDK |
| 無網絡自發請求 | 除用戶主動觸發外，不自發向任何伺服器發送數據 |
