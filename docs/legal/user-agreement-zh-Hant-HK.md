## 二、服務說明

| 項目 | 內容 |
|------|------|
| 應用名稱 | Notiee |
| 當前版本 | v1.0.5 |
| 核心功能 | 日程感知拍照記錄、純文字記錄、AI 知識提煉（OCR / 摘要 / 要點 / 待辦）、日曆與日程標籤管理、待辦管理（截止日期 / 提醒）、Spark AI 助手（對話 + Agent 操作）、語義檢索與深度聯想（相關筆記推薦） |

## 三、用戶註冊與帳戶

3.1 本應用提供**本地帳戶**功能，用戶可在應用內建立個人資料（暱稱、頭像等），所有帳戶資訊僅儲存在用戶本機裝置，不上傳至任何伺服器。
3.2 本應用**不提供**網絡帳戶註冊、登入或雲端同步帳戶功能。
3.3 所有用戶數據（拍記、待辦、AI 摘要、對話記錄等）預設儲存在用戶本機裝置。
3.4 如未來增加網絡帳戶功能，將另行通知並更新本協議。

## 六、AI 功能特別條款

6.1 **AI 服務提供方式**：用戶自行配置 API Key，連接用戶指定的 AI 服務商（如 OpenAI、DeepSeek、Anthropic、阿里雲百煉、火山引擎、MiniMax 等）。Notiee 不提供自有的 AI 雲端服務。

6.2 **數據處理說明**：
   - 文字和圖片將發送至用戶配置的 AI 服務商進行處理，Notiee 不在中間截留或儲存。
   - Spark AI 助手的對話內容（包括用戶訊息和 AI 回覆）將發送至用戶配置的 AI 服務商。
   - Agent 模式下，Spark 可能調用工具存取用戶的拍記、日程、待辦等本地數據，相關數據可能作為上下文發送至 AI 服務商。
   - 語義檢索功能預設在裝置本地計算向量；僅當用戶在實驗室手動開啟「高品質雲端檢索」時，才會將拍記文字發送至用戶配置的 AI 服務商的 Embedding 介面。詳情頁的「深度聯想」相關推薦固定使用本地向量，不外傳。

6.3 **WebFetch 功能**：Agent 模式下，Spark 可根據用戶指令抓取指定 URL 的網頁內容。此功能使用臨時網絡會話（不持久化 Cookie／緩存），並內置安全防護機制，禁止存取本地及內網地址。

6.4 **用戶責任**：用戶需自行獲取 API Key 並遵守對應 AI 服務商的使用條款和服務協議。

6.5 **AI 輸出免責**：AI 生成的摘要、待辦、對話回覆等內容僅供參考，不構成專業建議（包括但不限於法律、醫療、財務等領域的專業建議）。用戶應自行判斷 AI 輸出的準確性和適用性。
