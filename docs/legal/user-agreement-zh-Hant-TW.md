| 項目 | 內容 |
|------|------|
| 應用程式名稱 | Notiee |
| 當前版本 | v1.0.6 |
| 核心功能 | 日程感知拍照記錄、純文字記錄、AI 知識提煉（OCR / 摘要 / 要點 / 待辦）、日曆與日程標籤管理、待辦管理（截止日期 / 提醒）、Spark AI 助手（對話 + Agent 操作）、語義檢索與深度聯想（相關筆記推薦） |

3.3 所有使用者資料（拍記、待辦、AI 摘要、對話記錄等）預設儲存在使用者本機裝置。

## 六、AI 功能特別條款

6.1 **AI 服務提供方式**：使用者自行設定 API Key，連線使用者指定的 AI 服務商（如 OpenAI、DeepSeek、Anthropic、阿里雲百煉、火山引擎、MiniMax 等）。Notiee 不提供自有的 AI 雲端服務。

6.2 **資料處理說明**：
   - 文字和圖片將傳送至使用者設定的 AI 服務商進行處理，Notiee 不在中間截留或儲存。
   - Spark AI 助手的對話內容（包括使用者訊息和 AI 回覆）將傳送至使用者設定的 AI 服務商。
   - Agent 模式下，Spark 可能呼叫工具存取使用者的拍記、日程、待辦等本機資料，相關資料可能作為上下文傳送至 AI 服務商。
   - 語義檢索功能預設在裝置本機計算向量；僅當使用者在實驗室手動開啟「高品質雲端檢索」時，才會將拍記文字傳送至使用者設定的 AI 服務商的 Embedding 介面。詳情頁的「深度聯想」相關推薦固定使用本機向量，不外傳。

6.3 **WebFetch 功能**：Agent 模式下，Spark 可根據使用者指令抓取指定 URL 的網頁內容。此功能使用臨時網路會話（不持久化 Cookie／快取），並內建安全防護機制，禁止存取本機及內網地址。

6.4 **使用者責任**：使用者需自行取得 API Key 並遵守對應 AI 服務商的使用條款和服務條款。

6.5 **AI 輸出免責**：AI 產生的摘要、待辦、對話回覆等內容僅供參考，不構成專業建議（包括但不限於法律、醫療、財務等領域的專業建議）。使用者應自行判斷 AI 輸出的準確性和適用性。
