# Notiee 隱私權政策

**版本：v1.0.5**
**生效日期：2026 年 6 月 24 日**

---

## 一、引言

我們非常重視您的隱私。本隱私權政策旨在向您透明地說明 Notiee（以下簡稱「本應用程式」）收集哪些資訊、如何使用這些資訊、以及如何保護您的資料安全。

**核心理念：資料都在你手裡。** 本應用程式是一款本地優先的工具應用程式，您的所有記錄、筆記和對話都保存在您自己的裝置上。

---

## 二、資訊收集與使用

### 2.1 我們不收集的資訊

| 資訊類型 | 說明 |
|----------|------|
| 個人身份資訊 | 無網路帳戶系統，不收集姓名、電子郵件、手機號碼等身份資訊 |
| 位置資訊 | 不請求定位權限，不收集 GPS 座標 |
| 裝置識別碼 | 不收集 IDFA、IDFV 或其他裝置識別碼 |
| 使用行為分析 | 不整合任何分析/統計 SDK，無埋點追蹤 |
| 廣告識別碼 | 不整合廣告 SDK，無廣告追蹤 |
| 網路日誌 | 不記錄使用者的網路請求日誌 |

### 2.2 儲存在裝置本地的資訊

| 資訊類型 | 儲存位置 | 用途 |
|----------|----------|------|
| 拍攝的照片 | 裝置本地檔案系統 | 記錄內容展示與回顧 |
| OCR 文字、AI 摘要、要點 | 本地 JSON 檔案 | 搜尋與知識回顧 |
| 純文字記錄 | 本地 JSON 檔案 | 手動文字筆記 |
| 待辦事項 | 本地 JSON 檔案 | 任務管理（含截止日期、提醒標記） |
| 自訂資料夾、標籤、日程標籤 | 本地 JSON 檔案 | 分類與日程著色 |
| Spark 對話歷史 | 本地 JSON 檔案 | AI 對話記錄儲存與搜尋 |
| Spark 長期記憶 | 本地 JSON 檔案 | AI 助手個人化記憶 |
| 本地帳戶資料（暱稱、頭像） | 本地檔案系統 | 個人資料展示 |
| 語義向量索引（搜尋 / 深度聯想） | 本地檔案系統 | 拍記語義搜尋與相關筆記推薦（端側向量） |
| API Key（AI 金鑰） | iOS Keychain（硬體級加密） | 呼叫 AI 服務 |
| App 設定偏好（主題、語言、模型配置等） | UserDefaults | 個人化體驗 |
| 日曆日程資訊 | 記憶體中處理，不長期儲存 | 拍照時匹配日程上下文 |

### 2.3 傳送至第三方的資訊

以下場景中，資料會傳送至使用者**自行配置**的第三方 AI 服務商：

| 場景 | 傳送內容 | 接收方 | 使用者控制 |
|------|----------|--------|----------|
| AI 拍記處理 | 照片圖片資料 + 文字提示詞 | 使用者配置的 AI 服務商 | 使用者主動觸發拍照後自動處理，可關閉 AI 功能 |
| Spark 對話 | 使用者訊息 + 對話歷史上下文 | 使用者配置的 AI 服務商 | 使用者主動發起對話 |
| Spark Agent 操作 | 使用者指令 + 相關拍記/日程/待辦資料 | 使用者配置的 AI 服務商 | 使用者主動使用 Agent 模式 |
| WebFetch 網頁抓取 | 目標 URL（由使用者提供） | 目標網頁所在伺服器 | 僅在 Agent 模式下由使用者指令觸發 |
| 雲端語義檢索（可選） | 拍記文字摘要 | 使用者配置的 AI 服務商 Embedding 介面 | **預設關閉**，需在實驗室中手動開啟 |
| iCloud 同步（如開啟） | .tmn 加密歸檔檔案 | Apple iCloud Drive | 使用者手動觸發 |

> **重要說明**：以上所有 AI 服務呼叫均使用使用者**自行提供**的 API Key，傳送至使用者**自行選擇**的 AI 服務商。Notiee 不營運自有伺服器，不截留、不儲存任何傳送至第三方的資料。**詳情頁的「深度聯想」相關筆記推薦預設完全在裝置本地計算，不向任何伺服器傳送資料。**

## 四、資料儲存與安全

| 措施 | 說明 |
|------|------|
| 本地優先 | 所有記錄預設儲存在裝置本地，不依賴雲端 |
| Keychain 加密 | API Key 使用 iOS Keychain（硬體級安全區域加密）儲存，不寫入一般檔案，App 解除安裝後自動清除 |
| HTTPS 傳輸 | 所有 AI 服務呼叫使用 HTTPS 加密傳輸 |
| 無雲端留存 | Notiee 不營運自有伺服器，不收集、不儲存使用者內容資料 |
| iCloud 安全 | 如使用者手動啟用 iCloud 同步，資料儲存在使用者個人的 iCloud Drive，受 Apple 安全體系保護 |
| WebFetch 安全 | 使用臨時網路會話（不持久化 Cookie/快取），內建 SSRF 防護，禁止存取本地及內網位址（localhost、10.x、172.16-31.x、192.168.x 等） |
| 語義檢索本地化 | 預設使用 Apple NLEmbedding 端側向量引擎，所有向量計算在裝置本地完成，不上傳至任何伺服器 |
| 無網路自發請求 | 除使用者主動觸發 AI 處理、Spark 對話、WebFetch 或 iCloud 同步外，本應用程式不會自發向任何伺服器傳送資料 |

## 五、資料分享與揭露

5.1 **不向第三方出售、出租或交易使用者資料。**
5.2 僅在以下情況可能揭露使用者資料：
   - 法律法規要求
   - 保護開發者或他人的合法權益
   - 使用者明確同意
5.3 AI 服務呼叫資料傳送至使用者自行選擇的 AI 服務商，受該服務商自身的隱私權政策約束，與本應用程式無關。
5.4 WebFetch 抓取的網頁內容由目標網站提供，受該網站的使用條款約束。

## 八、Spark AI 助手隱私權說明

Spark 是本應用程式內建的 AI 助手，具有以下隱私權特性：

8.1 **對話內容**：Spark 的對話訊息（使用者輸入和 AI 回覆）會傳送至使用者配置的 AI 服務商進行處理。對話歷史儲存在裝置本地。
8.2 **Agent 模式**：當使用者使用 Agent 模式時，Spark 可能讀取使用者的拍記、日程、待辦等本地資料作為操作上下文，相關資料可能隨請求傳送至 AI 服務商。
8.3 **WebFetch**：Agent 模式下可根據使用者指令抓取網頁內容，使用臨時安全會話，不持久化任何網路資料。
8.4 **長期記憶**：Spark 的記憶系統（使用者偏好、習慣等）儲存在裝置本地，不上傳至任何伺服器。
8.5 **隱私同意**：首次使用 Spark 時，使用者需閱讀並同意 Spark 隱私同意書。

## 附錄 A：資料生命週期

```
拍攝 → 本地儲存 → [使用者觸發 AI 處理] → 傳送至 AI 服務商 → 返回結果 → 本地儲存
                                ↓
                        [Spark 對話] → 傳送至 AI 服務商 → 返回結果 → 本地儲存
                                ↓
                        [Agent 操作] → 讀取本地資料 → 傳送至 AI 服務商 → 執行操作
                                ↓
                        [WebFetch] → 臨時抓取網頁 → 返回正文 → 不持久化
                                ↓
                        [雲端語義檢索（可選）] → 傳送文字至 Embedding 介面 → 返回向量 → 本地儲存
                                ↓
                        [iCloud 同步] → 傳送至 iCloud Drive
                                ↓
                        [使用者刪除] → 本地檔案移除 + AI 服務商端依其政策處理
```
