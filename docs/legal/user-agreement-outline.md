## 三、用户注册与账户

## 四、用户行为规范

### 4.1 允许的行为
- 个人学习、工作记录用途
- 拍摄课堂笔记、会议记录等合法内容

### 4.2 禁止的行为
- 利用 App 拍摄、存储、传播违法内容（涉黄、涉暴、侵犯他人隐私、侵犯知识产权等）
- 对 App 进行逆向工程、反编译
- 利用 App 进行任何违反中国法律法规的活动

## 六、AI 功能特别条款

| 要点 | 内容 |
|------|------|
| AI 服务提供方式 | 用户自行配置 API Key，连接用户指定的 AI 服务商（如 OpenAI、DeepSeek 等） |
| 数据处理说明 | 文本和图片将发送至用户配置的 AI 服务商进行处理，Notiee 不在中间截留或存储 |
| 用户责任 | 用户需自行获取 API Key 并遵守对应 AI 服务商的使用条款 |
| AI 输出免责 | AI 生成的摘要、待办等内容仅供参考，不构成专业建议 |

## 七、第三方服务

- 用户配置的 AI 服务商（OpenAI、DeepSeek 等）为第三方服务
- 日历数据读取涉及 Apple EventKit 服务
- 用户需自行遵守第三方服务的使用条款

- App 按"现状"提供，不保证无错误或无中断

- 因用户违反本协议或法律法规产生的后果由用户承担
- 因不可抗力（如网络故障、设备损坏）导致的数据丢失，App 不承担责任
- 用户应自行备份重要数据
