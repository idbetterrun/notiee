# Notiee 隐私政策

**版本：v1.0.5**
**生效日期：2026 年 6 月 24 日**

---

## 一、引言

我们非常重视您的隐私。本隐私政策旨在向您透明地说明 Notiee（以下简称"本应用"）收集哪些信息、如何使用这些信息、以及如何保护您的数据安全。

**核心理念：数据都在你手里。** 本应用是一款本地优先的工具应用，您的所有记录、笔记和对话都保存在您自己的设备上。

---

## 二、信息收集与使用

### 2.1 我们不收集的信息

| 信息类型 | 说明 |
|----------|------|
| 个人身份信息 | 无网络账户系统，不收集姓名、邮箱、手机号等身份信息 |
| 位置信息 | 不请求定位权限，不收集 GPS 坐标 |
| 设备标识符 | 不收集 IDFA、IDFV 或其他设备标识符 |
| 使用行为分析 | 不集成任何分析/统计 SDK，无埋点追踪 |
| 广告标识 | 不集成广告 SDK，无广告追踪 |
| 网络日志 | 不记录用户的网络请求日志 |

### 2.2 存储在设备本地的信息

| 信息类型 | 存储位置 | 用途 |
|----------|----------|------|
| 拍摄的照片 | 设备本地文件系统 | 记录内容展示与回顾 |
| OCR 文本、AI 摘要、要点 | 本地 JSON 文件 | 搜索与知识回顾 |
| 纯文本记录 | 本地 JSON 文件 | 手动文字笔记 |
| 待办事项 | 本地 JSON 文件 | 任务管理（含截止日期、提醒标记） |
| 自定义文件夹、标签、日程标签 | 本地 JSON 文件 | 分类与日程着色 |
| Spark 对话历史 | 本地 JSON 文件 | AI 对话记录保存与搜索 |
| Spark 长期记忆 | 本地 JSON 文件 | AI 助手个性化记忆 |
| 本地账户资料（昵称、头像） | 本地文件系统 | 个人资料展示 |
| 语义向量索引（搜索 / 深度联想） | 本地文件系统 | 拍记语义搜索与相关笔记推荐（端侧向量） |
| API Key（AI 密钥） | iOS Keychain（硬件级加密） | 调用 AI 服务 |
| App 设置偏好（主题、语言、模型配置等） | UserDefaults | 个性化体验 |
| 日历日程信息 | 内存中处理，不长期存储 | 拍照时匹配日程上下文 |

### 2.3 发送至第三方的信息

以下场景中，数据会发送至用户**自行配置**的第三方 AI 服务商：

| 场景 | 发送内容 | 接收方 | 用户控制 |
|------|----------|--------|----------|
| AI 拍记处理 | 照片图片数据 + 文本提示词 | 用户配置的 AI 服务商 | 用户主动触发拍照后自动处理，可关闭 AI 功能 |
| Spark 对话 | 用户消息 + 对话历史上下文 | 用户配置的 AI 服务商 | 用户主动发起对话 |
| Spark Agent 操作 | 用户指令 + 相关拍记/日程/待办数据 | 用户配置的 AI 服务商 | 用户主动使用 Agent 模式 |
| WebFetch 网页抓取 | 目标 URL（由用户提供） | 目标网页所在服务器 | 仅在 Agent 模式下由用户指令触发 |
| 云端语义检索（可选） | 拍记文本摘要 | 用户配置的 AI 服务商 Embedding 接口 | **默认关闭**，需在实验室中手动开启 |
| iCloud 同步（如开启） | .tmn 加密归档文件 | Apple iCloud Drive | 用户手动触发 |

> **重要说明**：以上所有 AI 服务调用均使用用户**自行提供**的 API Key，发送至用户**自行选择**的 AI 服务商。Notiee 不运营自有服务器，不截留、不存储任何发送至第三方的数据。**详情页的「深度联想」相关笔记推荐默认完全在设备本地计算，不向任何服务器发送数据。**

## 四、数据存储与安全

| 措施 | 说明 |
|------|------|
| 本地优先 | 所有记录默认存储在设备本地，不依赖云端 |
| Keychain 加密 | API Key 使用 iOS Keychain（硬件级安全区域加密）存储，不写入普通文件，App 卸载后自动清除 |
| HTTPS 传输 | 所有 AI 服务调用使用 HTTPS 加密传输 |
| 无云端留存 | Notiee 不运营自有服务器，不收集、不存储用户内容数据 |
| iCloud 安全 | 如用户手动启用 iCloud 同步，数据存储在用户个人的 iCloud Drive，受 Apple 安全体系保护 |
| WebFetch 安全 | 使用临时网络会话（不持久化 Cookie/缓存），内置 SSRF 防护，禁止访问本地及内网地址（localhost、10.x、172.16-31.x、192.168.x 等） |
| 语义检索本地化 | 默认使用 Apple NLEmbedding 端侧向量引擎，所有向量计算在设备本地完成，不上传至任何服务器 |
| 无网络自发请求 | 除用户主动触发 AI 处理、Spark 对话、WebFetch 或 iCloud 同步外，本应用不会自发向任何服务器发送数据 |

## 五、数据分享与披露

5.1 **不向第三方出售、出租或交易用户数据。**
5.2 仅在以下情况可能披露用户数据：
   - 法律法规要求
   - 保护开发者或他人的合法权益
   - 用户明确同意
5.3 AI 服务调用数据发送至用户自行选择的 AI 服务商，受该服务商自身的隐私政策约束，与本应用无关。
5.4 WebFetch 抓取的网页内容由目标网站提供，受该网站的使用条款约束。

## 八、Spark AI 助手隐私说明

Spark 是本应用内置的 AI 助手，具有以下隐私特性：

8.1 **对话内容**：Spark 的对话消息（用户输入和 AI 回复）会发送至用户配置的 AI 服务商进行处理。对话历史保存在设备本地。
8.2 **Agent 模式**：当用户使用 Agent 模式时，Spark 可能读取用户的拍记、日程、待办等本地数据作为操作上下文，相关数据可能随请求发送至 AI 服务商。
8.3 **WebFetch**：Agent 模式下可根据用户指令抓取网页内容，使用临时安全会话，不持久化任何网络数据。
8.4 **长期记忆**：Spark 的记忆系统（用户偏好、习惯等）保存在设备本地，不上传至任何服务器。
8.5 **隐私同意**：首次使用 Spark 时，用户需阅读并同意 Spark 隐私同意书。

## 附录 A：数据生命周期

```
拍摄 → 本地存储 → [用户触发 AI 处理] → 发送至 AI 服务商 → 返回结果 → 本地存储
                                ↓
                        [Spark 对话] → 发送至 AI 服务商 → 返回结果 → 本地存储
                                ↓
                        [Agent 操作] → 读取本地数据 → 发送至 AI 服务商 → 执行操作
                                ↓
                        [WebFetch] → 临时抓取网页 → 返回正文 → 不持久化
                                ↓
                        [云端语义检索（可选）] → 发送文本至 Embedding 接口 → 返回向量 → 本地存储
                                ↓
                        [iCloud 同步] → 发送至 iCloud Drive
                                ↓
                        [用户删除] → 本地文件移除 + AI 服务商端依其政策处理
```

## 附录 B：技术实现隐私要点

| 实现 | 说明 |
|------|------|
| 无埋点 | 不集成任何分析/统计 SDK |
| 无广告 | 不集成广告 SDK |
| 无网络自发请求 | 除用户主动触发外，不自发向任何服务器发送数据 |
| API Key 本地化 | 存储在 Keychain，App 卸载后自动清除 |
| 传输加密 | 所有 AI 请求使用 HTTPS |
| WebFetch 临时会话 | 使用 `URLSessionConfiguration.ephemeral`，不持久化 Cookie/缓存 |
| WebFetch SSRF 防护 | 禁止 localhost、内网 IP、IPv6 本地地址 |
| 端侧向量引擎 | 默认使用 Apple NLEmbedding，语义计算在设备本地完成 |
| 云端检索可选 | 云端 Embedding 默认关闭，需用户手动开启 |
