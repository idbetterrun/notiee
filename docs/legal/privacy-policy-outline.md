# Notiee 隐私政策 编写大纲

> 本文档为大纲，供其他 Agent 或开发者据此编写正式隐私政策文本。
> 目标读者：使用 Notiee App 的个人用户。政策语言：中文，透明易懂。

---

## 一、引言

- 隐私政策的全称、生效日期、版本号（v1.0.1）
- 我们重视你的隐私。本政策说明我们收集什么、如何使用、如何保护
- 政策适用范围：Notiee App（iOS 版本）

---

## 二、信息收集与使用

### 2.1 我们不收集的信息

| 信息类型 | 说明 |
|----------|------|
| 个人身份信息 | 无账户系统，不收集姓名、邮箱、手机号 |
| 位置信息 | 不请求定位权限 |
| 设备标识符 | 不收集 IDFA / IDFV |
| 使用行为分析 | 无埋点、无统计 SDK |
| 广告标识 | 无广告、无追踪 |

### 2.2 存储在设备本地的信息

| 信息类型 | 存储位置 | 用途 |
|----------|----------|------|
| 拍摄的照片 | 设备本地文件系统 | 记录内容展示 |
| OCR 文本、AI 摘要 | 本地 JSON 文件 | 搜索与回顾 |
| 待办事项 | 本地 JSON 文件 | 任务管理 |
| 自定义文件夹、标签 | 本地 JSON 文件 | 分类管理 |
| API Key（AI 密钥） | iOS Keychain 加密存储 | 调用 AI 服务 |
| App 设置偏好（主题、语言等） | UserDefaults | 个性化体验 |
| 日历日程信息 | 内存中处理，不长期存储 | 拍照时匹配日程上下文 |

### 2.3 发送至第三方的信息

| 场景 | 发送内容 | 接收方 | 说明 |
|------|----------|--------|------|
| AI 处理 | 照片图片数据 + 文本提示词 | 用户配置的 AI 服务商 | 用户自行选择服务商（OpenAI/DeepSeek 等），加密传输 |
| iCloud 同步（如开启） | .tmn 加密归档文件 | Apple iCloud Drive | 用户手动触发，数据存储在用户个人 iCloud 空间 |

## 三、权限使用说明

| 权限 | 用途 | 是否必需 | 可否撤回 |
|------|------|----------|----------|
| 相机 | 拍摄课堂笔记/会议记录 | 核心功能，必需 | 系统设置中关闭 |
| 麦克风 | 语音记录（如开启） | 可选 | 系统设置中关闭 |
| 相册 | 导入已有图片 | 可选 | 系统设置中关闭 |
| 日历 | 读取系统日历，匹配当前日程 | 可选（关闭后手动选日程） | 系统设置中关闭 |
| 语音识别 | 语音转文字 | 可选 | 系统设置中关闭 |
| 通知 | 日程提醒 | 可选 | 系统设置中关闭 |

## 四、数据存储与安全

| 措施 | 说明 |
|------|------|
| 本地优先 | 所有记录默认存储在设备本地 |
| Keychain 加密 | API Key 使用 iOS Keychain（硬件级加密）存储，不写入普通文件 |
| HTTPS 传输 | AI 服务调用使用 HTTPS 加密传输 |
| 无云端留存 | Notiee 不运营自己的服务器，不收集、不存储用户内容数据 |
| iCloud 安全 | 如用户手动启用 iCloud 同步，数据存储在用户个人的 iCloud Drive，受 Apple 安全体系保护 |

---

## 五、数据分享与披露

- **不向第三方出售、出租用户数据**
- 仅在以下情况披露：法律要求、保护合法权益、用户明确同意
- AI 服务调用数据发送至用户自行选择的 AI 服务商，受该服务商隐私政策约束

---

## 六、用户权利

| 权利 | 说明 |
|------|------|
| 访问权 | 所有数据在 App 内可直接查看 |
| 导出权 | 支持一键导出所有记录为 .tmn 文件 |
| 删除权 | 可在 App 内删除单条记录或清空全部数据 |
| 撤回同意 | 可在系统设置中关闭任意权限 |
| 注销 | 当前无账户系统，卸载 App 即清除所有本地数据 |

---

## 七、未成年人保护

- App 面向学生和职场人士，不专门面向 14 岁以下儿童
- 如监护人发现未成年人未经同意使用 App，可联系删除数据

---

## 八、政策更新

- 保留随时更新本政策的权利
- 重大变更将通过 App 内弹窗通知
- 更新后继续使用视为同意

## 附录 A：数据生命周期

```
拍摄 → 本地存储 → [用户触发 AI 处理] → 发送至 AI 服务商 → 返回结果 → 本地存储
                                ↓
                        [用户触发 iCloud 同步] → 发送至 iCloud Drive
                                ↓
                        [用户删除] → 本地文件移除 + AI 服务商端依其政策处理
```

## 附录 B：技术实现隐私要点

| 实现 | 说明 |
|------|------|
| 无埋点 | App 不集成任何分析/统计 SDK |
| 无广告 | App 不集成广告 SDK |
| 无网络请求（除用户主动触发） | App 不自发向任何服务器发送数据 |
| API Key 本地化 | 存储在 Keychain，App 卸载后自动清除 |
| 传输加密 | 所有 AI 请求使用 HTTPS |
