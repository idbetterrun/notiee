# Notiee 1.0.3 更新日志

> 发布日期：2026年6月4日

---

## Spark AI 伴侣 🎉

**全新第四标签页**，你的私人 AI 助手正式上线！

- **智能对话**：可以询问任何关于拍记、学习进度的问题，Spark 会基于你的笔记给出精准回答
- **对话历史**：所有对话自动保存，支持查看、搜索和批量管理
- **记忆系统**：Spark 会自动记住你的名字、偏好、习惯等信息，并在后续对话中自然提起
- **隐私安全**：严格的身份保护和注入攻击防护，不会泄露你的任何数据

## Spark 风格自定义

在设置 · 大模型中可为 Spark 选择不同聊天风格：

- **6 种预设风格**：默认、温柔知心、犀利毒舌、简洁高效、幽默风趣、学究严谨
- **自定义风格**：支持添加任意风格指令，打造专属 AI 伴侣

## Spark Token 追踪

回顾页新增 **Spark 耗费Token估计**，独立统计 AI 对话的 Token 消耗，与拍记 Token 消耗分开显示。

## 多语言全面适配

- 完善**繁体中文**与 **English** 的全界面翻译，覆盖 Spark、设置、回顾等所有页面
- 优化英文译文质量，告别机翻感
- `Today` 与 `Spark` 在三种语言下保持一致

## 架构与性能优化

- 管理架构重组：NotieeStore 拆分为 4 个专职管理器，职责更清晰
- 设置页拆分：大设置页（900+ 行）拆为 7 个独立页面，加载速度大幅提升
- UserDefaults Key 集中化管理：代码更规范，减少硬编码

## AI Pipeline 修复

- 移除无限重试循环，网络异常时快速返回错误，不再卡死
- 引入指数退避重试机制，提升处理可靠性
- 新增 JSON 数据迁移系统，支持未来数据结构升级

## 其他修复

- 系统日历事件 ID 匹配增强：重启后不再因 ID 变化而丢失日程关联
- 今日页面导航优化，返回路径更清晰
- 修复 Tab 栏多语言重复键问题

---

> **注意**：1.0.3 为 Spark 功能的首次发布版本。后续版本将继续优化对话体验、知识图谱和语义搜索功能。
