### 1.1 官网目标

### 1.2 技术选型

| 维度 | 选择 | 理由 |
|------|------|------|
| **框架** | Next.js (App Router) | SEO 友好，静态生成，Vercel 一键部署 |
| **样式** | Tailwind CSS | 快速开发，响应式友好 |
| **国际化** | next-intl | 路由级多语言（`/zh-Hans`、`/zh-Hant`、`/en`） |

| **域名** | 待定 | 建议 `notiee.app` 或 `notiee.com` |
| **分析** | 待定（Umami / Plausible） | 隐私友好的访问统计 |

- **iOS 18 相机控制按钮**：硬件按键直接启动 Notiee 相机
- **从相册导入**：也支持从系统相册选取已有照片

- **全文搜索**：搜索标题、AI 摘要、OCR 识别文本
- **多级文件夹**：自定义文件夹层级，灵活组织

  - 关联的待办事项

#### Notti - AI 对话助手
- **上下文对话**：以近期锚点 + 语义命中的有界笔记上下文回答，并提供可回溯引用

  - 日历查询：查看课程/会议安排

  - 待办管理：创建和查询待办事项
  - 记忆系统：有界检索与经确认的永久遗忘
  - 搜索笔记：语义搜索知识库

- **记忆系统**：本地 AES-GCM 加密存储；融合语义、BM25、实体和时间信号召回 Top-K；区分重复证据、实际使用、衰减、合并、替代、过期与归档；敏感记忆确认后才生效

#### 常见问题 (FAQ)

**Q: 为什么需要自己提供 API Key？**
A: Notiee 不收取订阅费用。AI 处理成本由你选择的 AI 厂商按用量收取。这样你可以选择最适合自己的厂商和模型，成本完全透明。

**Q: 我拍的照片存在哪里？**
A: 所有照片、笔记和 AI 处理结果都存储在 iPhone 本地。我们不上传你的数据到任何服务器。你可以通过 TMN 格式导出备份。

**Q: Notiee 支持哪些语言？**
A: 应用界面支持简体中文、繁體中文、English。AI 识别和处理支持大多数语言，中文和英文效果最佳。

**Q: 离线能用吗？**
A: 拍摄和本地浏览完全支持离线使用。AI 处理需要网络连接（调用 API），但 Notiee 设计了离线队列机制——网络恢复后自动继续处理。

**Q: 如何备份数据？**
A: 进入「设置 → 备份与恢复」，选择「导出 TMN 归档」。TMN 格式包含所有照片、摘要、待办等完整数据。导入时选择对应的 .tmn 文件即可。

**Q: AI 处理一次大概花多少钱？**
A: 取决于你选择的厂商和模型。以 DeepSeek 为例，处理一张板书的 OCR + 摘要大约花费 0.001-0.005 元人民币。部分厂商有免费额度。

**Q: 可以导出到其他笔记软件吗？**
A: 当前支持 TMN 格式导出。未来计划支持 Markdown、PDF 等格式导出。

- 统一风格的黑色/绿色按钮
- 使用 Apple 官方 badge 样式
- 链接到 App Store 应用页面

### 4.5 SEO Meta

每个页面需要：
```typescript
interface PageMeta {
  title: string;           // 页面标题（含 Notiee 品牌名）
  description: string;     // 页面描述（150 字符以内）
  ogImage: string;         // Open Graph 分享图片
  canonical: string;       // 规范链接
  alternateLanguages: {    // 替代语言链接
    'zh-Hans': string;
    'zh-Hant': string;
    'en': string;
  };
}
```

## 五、国际化方案

### 5.1 翻译文件结构

```
messages/
├── zh-Hans.json    # 简体中文
├── zh-Hant.json    # 繁體中文
└── en.json         # English
```

### 5.2 内容策略

| 内容类型 | 策略 | 说明 |
|----------|------|------|
| 页面 UI 文案 | 三语翻译文件 | 按钮、标签、固定文案 |
| 功能描述 | 三语翻译文件 | 功能名称和说明 |
| 博客文章 | CMS 按 locale 独立撰写 | 不做机翻，每语言写原文 |
| 隐私/协议 | 从已有 PDF 提取 | 法律文档需精确 |
| 帮助文档 | 三语翻译文件 + 独立文章 | FAQ 做翻译，教程写原文 |

### 5.3 语言检测逻辑

1. 优先使用用户手动选择的语言（Cookie/Storage）
2. 其次使用浏览器 `Accept-Language` 头
3. 默认回退到简体中文

## 六、CMS 方案对比

| 维度 | Contentful | Strapi（自建） | Notion as CMS |
|------|------------|---------------|---------------|
| **费用** | 免费层 100万次 API/月 | 需自建服务器（≈$5-20/月） | 免费 |
| **国际化** | 原生支持 Locale 字段 | 需插件 i18n | 需手动管理 |
| **编辑体验** | 专业 CMS 界面 | 自托管界面 | Notion 编辑器 |
| **API** | REST + GraphQL | REST + GraphQL | 非官方 API |
| **图片** | 内置 CDN | 需自己处理 | Notion 存储 |
| **适合** | 非技术人员编辑 | 完全控制 | 低成本快速启动 |

**推荐：Contentful**，免费层足够博客使用，国际化支持最好。
